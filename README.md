# Abhishek Kumar — AI/ML Portfolio

Modern responsive portfolio for Abhishek Kumar, B.Tech Artificial Intelligence student.

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Create a GitHub repository (for example `abhishek-portfolio`).
2. Upload all files in this folder.
3. On Vercel, import the GitHub repository.
4. Framework Preset: Other.
5. Build Command: leave empty.
6. Output Directory: `.`
7. Deploy.

The site is a static HTML/CSS/JavaScript project, so no build step is required.
